## Нефункциональные требования
| ID | Измеримое требование |
|---|---|
| NFR-01 | Каталог 1000 книг отвечает ≤2.0 с на стенде 4 vCPU/8 GB RAM. |
| NFR-02 | Нет горизонтального скролла при ширине 360, 375, 768, 1024, 1440 px. |
| NFR-03 | Контраст ≥4.5:1 для обычного текста и ≥3:1 для крупного (WCAG 2.1 AA). |
| NFR-04 | Интерактивные области целевого размера ≥44×44 CSS px. |
| NFR-05 | Пароли хранятся только в виде хешей Django auth. |
| NFR-06 | Фотографии экземпляров ≤2 MB, разрешены JPG/PNG/WebP. |
| NFR-07 | Поддерживаются две последние стабильные версии Chrome, Firefox, Edge и Safari. |
| NFR-08 | SECRET_KEY/пароли БД берутся из env; DEBUG=0 в production. |
| NFR-09 | Основная навигация и отправка форм работают без JavaScript. |
| NFR-10 | Production-журнал ошибок хранится не менее 30 дней (настроить при деплое). |
