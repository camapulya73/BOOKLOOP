# Техническое задание BOOKLOOP · версия 1.0 · вариант 18
## 1. Наименование и область применения
BOOKLOOP — веб-сервис BookCrossing для публикации, поиска и обмена прочитанными книгами в локальных сообществах.
## 2. Основание для разработки
Учебное задание по проектированию информационных систем, макет BOOKLOOP в Figma, анализ аналогов (фактический отчёт оформляется по шаблону `research_template.md`).
## 3. Назначение разработки
Сервис позволяет размещать книги, искать их по каталогу, согласовывать обмен и сопровождать передачу между читателями.
## 4. Требования к программе
### 4.1 Функциональные характеристики
Роли: гость, пользователь, администратор. Гость просматривает главную, каталог и карточки; пользователь публикует книги, отправляет и управляет обменами, редактирует профиль; администратор модерирует публикации. Полный перечень FR-01—FR-20 в `requirements.md`.
### 4.2 Надёжность
Серверная валидация форм; контроль доступа по владельцу и роли; ограничения уникальности и рейтинга в БД; Собственная модель `core.Reader` (email как USERNAME_FIELD) и Django password hasher для хеширования паролей. Перед production — резервное копирование ежедневно.
### 4.3 Условия эксплуатации
Python 3.11+, Django 4.2+, современный браузер; локальная разработка на компьютере с 4 GB RAM и SQLite.
### 4.4 Технические средства
Учебный стенд: 2 CPU, 4 GB RAM, 1 GB свободного диска; демонстрационный сервер: рекомендуется 4 CPU/8 GB RAM.
### 4.5 Информационная и программная совместимость
- Сервер: Python 3.11+, Django 4.2+.
- БД: SQLite или PostgreSQL.
- Клиент: HTML5, CSS3, JavaScript без frontend-фреймворков.
- Адаптивные точки: 360, 768, 1024, 1440 px.
- Исходный код хранится в Git; секреты не коммитятся; конфигурация через env.
### 4.6 Программная документация
README, ER-модель, описание моделей и миграций, FR/NFR, трассировка, инструкция пользователя, тестовые сценарии.

## 6. Контроль и приёмка
Проект принят, если миграции применяются; создано ≥30 книг и ≥10 связанных записей; каталог ищет и фильтрует; гость не создаёт книги/обмены; пользователь не меняет чужие запросы; staff модерирует; адаптивность проверена на 360/375/768/1024/1440; контраст и тесты проверены; приложены ER, ORM/SQL, матрица и скриншоты.
